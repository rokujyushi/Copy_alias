## CopyAlias v2.2.0

エフェクトが持つ**全トラックバー項目をまとめてコピー / ペースト**できるようになりました。あわせて、メニューとダイアログの**英語表示**に対応しています。

### 新機能

**エフェクトのトラックバーを一括コピー / 一括ペースト**

オブジェクト設定でエフェクト名（`標準描画` など）を右クリックすると、そのエフェクトが持つトラックバー項目の値をまとめて持ち運べます。配下の設定項目を右クリックしても同じように使えます。

- 貼り付け先は**項目名の一致**で対応付けます。`標準描画` の `X` `Y` を別のスクリプト効果の `X` `Y` へ移すこともできます
- 反映する要素（値 / 移動方法 / 加速・減速 / 中間点無視 / パラメータ / 時間制御データ）と、適用する項目をダイアログで選べます
- 中間点の数が違うオブジェクトへ貼り付けても、値の個数を自動調整します
- リスト選択やチェックボックスなど、トラックバー以外の項目は自動的に除外されます

**言語対応**

AviUtl2 の言語設定に合わせて、メニュー名とダイアログの文言が切り替わります。英語の言語ファイルを同梱しています。他の言語を追加する方法は [README](../README.md) を参照してください。

**設定ファイル**

`C:\ProgramData\aviutl2\CopyAlias.ini` で動作を変更できます（初回起動時に自動生成）。現在は、オブジェクト設定の右クリックメニューを `CopyAlias` サブメニューにまとめるかどうかを選べます（既定はまとめない）。
