# CopyAlias 仕様書

- 対象バージョン: **CopyAlias v2.1.0**（Rust 実装）
- 対象ホスト: **AviUtl ExEdit2 2.1.4**（開発環境で動作確認したバージョン。`aviutl2.toml` は `aviutl2_version = "latest"` 運用のため随時更新される）
- プラグイン種別: **汎用プラグイン (.aux2)**
- 参照 SDK: `I:\aviutl2_sdk_mirror`（`include/aviutl2_sdk/plugin2.h`, `logger2.h`）
- ラッパ: Rust crate [`aviutl2` 0.39.0](https://crates.io/crates/aviutl2)

---

## 1. 概要

選択中オブジェクトの**エイリアス文字列（`.object` 相当の INI）**を軸に、AviUtl2 標準機能では届かない4つの編集操作を右クリックメニューへ追加するプラグイン。

| # | メニュー種別 | 表示名 | 概要 |
|---|---|---|---|
| 1 | オブジェクトメニュー | エイリアスをコピー | 選択中オブジェクトのエイリアスをクリップボードへ |
| 2 | オブジェクトメニュー | エイリアスの値をペースト | クリップボード INI から項目を選んで選択中オブジェクトへ部分適用 |
| 3 | レイヤーメニュー | クリップボードからオブジェクト貼り付け | クリップボードのエイリアスからオブジェクトを生成 |
| 4 | オブジェクトメニュー | エイリアスからパスをコピー | エイリアス内のパス候補を抽出して1つコピー |
| 5 | 設定項目メニュー | トラックバーのパラメータをコピー | 右クリックしたトラックバー項目の値・移動方法・加減速などをクリップボードへ |
| 6 | 設定項目メニュー | トラックバーのパラメータをペースト | 反映する要素を選んでトラックバー項目へ適用（中間点数は自動調整） |
| 7 | 設定項目メニュー | エフェクトのトラックバーを一括コピー | エフェクトが持つ全トラックバー項目の値をまとめてコピー |
| 8 | 設定項目メニュー | エフェクトのトラックバーを一括ペースト | 項目名の一致で対応付け、要素を選んでまとめて適用 |

設定項目メニュー（5〜8）は `CopyAlias\` のサブメニュー配下に登録する。

実装は [src/lib.rs](../src/lib.rs)（ロジック）、[src/gui.rs](../src/gui.rs)（ダイアログ）、[src/track.rs](../src/track.rs)（トラックバー値の分解・再構築）の3ファイル。

## 2. SDK 上の位置づけ

### 2.1 エントリポイント

SDK が要求する汎用プラグインの公開関数（`RegisterPlugin(HOST_APP_TABLE*)` ほか）は `aviutl2` crate の `#[aviutl2::plugin(GenericPlugin)]` / `register_generic_plugin!` マクロが生成する。本体側で実装しているのは以下だけ（[src/lib.rs:330](../src/lib.rs#L330)〜）。

```rust
#[aviutl2::plugin(GenericPlugin)]
struct CopyAlias;

impl aviutl2::generic::GenericPlugin for CopyAlias {
    fn new(_info: AviUtl2Info) -> AnyResult<Self>;        // DLL 初期化
    fn plugin_info(&self) -> GenericPluginTable;          // GetCommonPluginTable 相当
    fn register(&mut self, registry: &mut HostAppHandle); // RegisterPlugin 相当
}
```

`plugin_info()` は `COMMON_PLUGIN_TABLE`（`name` / `information`）を返す。SDK 上は `set_plugin_information` より `GetCommonPluginTable()` が推奨。

`register()` で行う処理:

| 処理 | 対応する SDK API |
|---|---|
| `EDIT_HANDLE.init(registry.create_edit_handle())` | `HOST_APP_TABLE::create_edit_handle` |
| `registry.register_menus::<CopyAlias>()` | `register_object_menu` / `register_layer_menu` / `register_object_item_menu` |

メニュー登録に使う属性と対応する SDK API:

| 属性 | 表示場所 | SDK API |
|---|---|---|
| `#[object(name = ...)]` | レイヤー編集でオブジェクト選択時の右クリック | `register_object_menu` |
| `#[layer(name = ...)]` | レイヤー編集でオブジェクト未選択時の右クリック | `register_layer_menu` |
| `#[object_item(name = ...)]` | オブジェクト設定ウィンドウの設定項目の右クリック | `register_object_item_menu`（`allow_effect_only = false`） |
| `#[object_item_and_effect(name = ...)]` | 同上に加えて**エフェクト名の右クリック**（`item` が `None` で呼ばれる） | `register_object_item_menu`（`allow_effect_only = true`） |

`#[object_item]` のコールバックは `(ObjectHandle, effect: &str, effect_index: usize, item: &str)` を受け取り、**編集セクションの外側**で呼ばれる（SDK の `register_object_item_menu_param` 版）。メニュー名に `\` を含めると階層化できる仕様だが、本プラグインは全てフラットで登録している。

### 2.2 編集セクション

全ての編集操作は `EDIT_HANDLE::call_edit_section` 相当の `EDIT_HANDLE.call_edit_section(|edit_section| ...)` 内で行う。SDK 仕様上の前提:

- コールバックは**メインスレッド**から呼ばれ、その間プロジェクトは**編集ロック**状態になる
- コールバック内で行った編集は**まとめて1つの Undo 単位**として登録される
- ファイル出力中など編集不可の状態では呼び出し自体が失敗する
- **フレーム番号・レイヤー番号は 0 始まり**（UI 表示とは 1 ずれる）

### 2.3 使用している EDIT_SECTION API

| 本プラグインの呼び出し | SDK 関数 | 用途 |
|---|---|---|
| `get_selected_objects()` | `get_selected_object_num` + `get_selected_object` | 選択中オブジェクト列挙 |
| `get_object_alias(&obj)` | `get_object_alias` | エイリアス（UTF-8）取得 |
| `get_object_layer_frame(&obj)` | `get_object_layer_frame` | `layer` / `start` / `end` 取得 |
| `obj.count_effect(name)` | `count_object_effect` | 同名エフェクトの個数確認 |
| `obj.get_effect_item(name, index, key)` | `get_object_item_value`（`効果名:n` 形式） | 設定項目の読み出し |
| `obj.set_effect_item(name, index, key, value)` | `set_object_item_value`（`効果名:n` 形式） | 設定項目の書き込み |
| `obj.get_track_info(name, index, key)` | `get_object_track_info` | トラックバー項目かの判定・時間制御の有無 |
| `obj.get_section_num()` | `get_object_section_num` | 区間数（＝中間点数+1）の取得 |
| `create_object_from_alias(alias, layer, frame, 0)` | `create_object_from_alias` | エイリアスからオブジェクト生成 |
| `edit_section.info.layer` / `.frame` | `EDIT_INFO` | カーソル位置の取得 |
| `aviutl2::logger::write_info_log` / `write_warn_log` | `LOG_HANDLE::info` / `warn` | ログウィンドウへの出力 |

> `set_effect_item` の第2引数 `effect_index` は、SDK の「同名エフェクトが複数ある場合の `":n"` サフィックス指定」に対応する（`set_object_item_value(obj, L"ぼかし:1", ...)` と等価）。

> `get_track_info` の戻り値は3状態になる。**`Err`** = SDK 呼び出しが失敗（＝トラックバー項目ではない）、**`Ok(None)`** = トラックバーだが移動無し（`TRACK_INFO::mode` が `nullptr`）、**`Ok(Some)`** = 移動ありのトラックバー。本プラグインはこの区別をトラックバー項目の判定に使っている。

## 3. エイリアス（`.object`）データ仕様

### 3.1 フォーマット

`create_object_from_alias` / `get_object_alias` が扱うのは、エイリアスファイル `.object` と同一フォーマットの **UTF-8 INI**。

```ini
[Object]                 ; オブジェクト単位のメタ情報
layer=3
frame=87,167
[Object.0]               ; 0番目のエフェクト
effect.name=図形         ; エフェクト識別子（必須）
図形の種類=円
サイズ=100
[Object.1]
effect.name=標準描画
X=0.00
拡大率=100.000
```

### 3.2 本プラグインのパース規約

パーサは `rust-ini` の `load_from_str_noescape`（バックスラッシュを**エスケープとして解釈しない** = Windows パスをそのまま保持）を使用。先頭 BOM（`U+FEFF`）は除去する。

| 規約 | 内容 | 実装位置 |
|---|---|---|
| ブロック分割 | `[Object]` セクション出現ごとに新しいブロック（＝1オブジェクト）を開始 | [lib.rs:270](../src/lib.rs#L270) |
| セクション判定 | `Object.N`（大小文字無視）のみエフェクトとして採用 | [lib.rs:43](../src/lib.rs#L43) |
| `effect.name` | エフェクト識別子として抽出し、プロパティ一覧からは除外 | [lib.rs:288](../src/lib.rs#L288) |
| 非表示ルール | `effect.name` が無いセクション、プロパティが0件のセクションは対象外 | [lib.rs:306](../src/lib.rs#L306) |
| `[Object]` メタ | `frame` などのメタ情報は適用対象に含めない（ブロック区切りとしてのみ使用） | [lib.rs:270](../src/lib.rs#L270) |
| occurrence | 同名 `effect.name` はブロック内の**出現順（0始まり）**で連番付与 | [lib.rs:304](../src/lib.rs#L304) |

パース結果は `ApplyItem { block_index, effect_name, occurrence, property_key, value }` のフラットな列になる。

### 3.3 トラックバー値のフォーマット

トラックバー項目の値は1行の中に移動情報まで含まれる。[src/track.rs](../src/track.rs) がこの分解・再構築を担当する。

```ini
拡大率=100.000                                        ; 移動無し（単一値）
X=0.00,100.00,直線移動,3                              ; 値...,移動方法,フラグ
X=0.00,50.00,100.00,直線移動,0                        ; 中間点1つ → 値は区間数+1個
X=0.0,0.0,ランダム移動,4|0.0001                       ; フラグ|パラメータ
X=0.000,0.000,mode@script,6|0|0,0,0,0,1,0.98,0.5,0    ; ...|時間制御データ
```

| 要素 | 内容 |
|---|---|
| 値 | 区間ごとの値。**個数 = 区間数 + 1**（`get_object_section_num` + 1） |
| 移動方法 | `直線移動` などの名称、またはスクリプト移動の `名前@スクリプト`。省略時は移動無し |
| フラグ | `1 = 加速` / `2 = 減速` / `4 = 中間点無視` / `8 = 参照式` のビット和 |
| パラメータ | フラグの後に `\|` 区切りで続くパラメータ欄の内容。移動方法のスクリプトパラメータのほか、**参照式**（パラメータ欄の右クリックメニューから設定。実データ `直線移動(時間制御),8\|X*2`）が入る |
| 時間制御データ | さらに `\|` 区切りで続くカーブデータ（カンマ区切りの数値列） |

分解時の規約（`track::parse`）:

- 先頭から連続する**数値トークンが値**、最初の非数値トークンが**移動方法**
- 移動方法より後ろは一旦カンマで再結合してから `|` で分割する（時間制御データがカンマを含むため）
- パラメータと時間制御データの区別:
  - 対象項目の `TrackInfo::timecontrol` が `false` なら余りは**パラメータ**で確定
  - 不明な場合は要素数で推定し、**4要素以上をカンマで含むものを時間制御データ**とみなす
- 値は小数桁数の書式を保つため**文字列のまま**保持する

## 4. 機能仕様

### 4.1 エイリアスをコピー（オブジェクトメニュー）

[src/lib.rs:358](../src/lib.rs#L358)

1. `get_selected_objects()` を取得。**0件なら何もせず終了**（フォーカスオブジェクトへのフォールバックは行わない）
2. 各オブジェクトの `get_object_alias()` を取得し、空文字列と取得失敗を除外
3. 全件を **CRLF (`\r\n`) 連結**してクリップボードへ（`arboard` 経由の `CF_UNICODETEXT`）
4. 有効なエイリアスが1件も無ければ何もしない

### 4.2 エイリアスの値をペースト（オブジェクトメニュー）

[src/lib.rs:397](../src/lib.rs#L397)

**処理順序が仕様上重要**：ダイアログ表示中に選択状態が変わっても影響を受けないよう、**メニュー実行時点の選択オブジェクトを先に確定**してから編集セクションを抜け、ダイアログを表示する。

1. 編集セクション① — 選択オブジェクトを取得。0件なら情報ログを出して終了
2. クリップボードのテキストを取得
3. §3.2 の規約で `ApplyItem` 列へパース。0件なら「表示対象なし」のログを出して終了
4. **プロパティ選択ダイアログ**（§5.1）を表示。キャンセル時は何もしない／全項目未チェックなら何もしない
5. 編集セクション② — 選択オブジェクト × チェック済み項目の総当たりで適用
   - `count_effect(effect_name) <= occurrence` の場合は**エフェクト不一致としてスキップ**
   - 適用先が**トラックバー項目の場合は値の個数を自動調整**する（§4.2.1）
   - `set_effect_item(effect_name, occurrence, key, value)` が失敗しても**中断せず継続**
   - 適用は INI の並び順で行うため、同一キーが重複する場合は**後勝ち**
6. 集計をログ出力： `適用対象オブジェクト / 試行数 / 適用成功 / エフェクト不一致スキップ / 設定失敗 / 値数調整`

#### 4.2.1 トラックバー項目の値数調整

エイリアスの値はコピー元オブジェクトの中間点数に依存する（§3.3）。中間点数の異なるオブジェクトへ貼ると値の個数が合わないため、適用直前に対象へ合わせる。

- `get_track_info` が成功する項目（＝トラックバー項目）のみ対象。それ以外は値をそのまま渡す
- コピー元が**移動無し**（単一値）の場合は調整しない
- 値の個数を対象の**区間数 + 1** に合わせる（多ければ先頭から切り詰め、少なければ末尾値で補完）
- 移動方法・フラグ・パラメータ・時間制御データは**触らない**。要素単位の選択が必要な場合は §4.6 を使う

適用対象は「現在選択中の**全**オブジェクト」であり、コピー元とエフェクト構成が一致しないオブジェクトはスキップされるだけで、エラーにはならない。

### 4.3 クリップボードからオブジェクト貼り付け（レイヤーメニュー）

[src/lib.rs:484](../src/lib.rs#L484)

1. 編集セクション① — **貼り付け基準位置**を確定
   - 選択オブジェクトがある場合: 先頭選択オブジェクトの `layer` と開始フレーム `start`
   - 無い場合: `EDIT_INFO` の現在のカーソル `layer` / `frame`
2. クリップボードテキストを `[Object]` 行を区切りに**複数エイリアスへ分割**（[lib.rs:85](../src/lib.rs#L85)）
   - 改行は `\r\n` / `\r` → `\n` に正規化
   - `[Object]` が1つも無い場合は全体を1件のエイリアスとして扱う
3. 各エイリアスから `layer` / `frame`（先頭の数値）を抽出（[lib.rs:61](../src/lib.rs#L61)）
   - 探索順は `[Object]` → `[0]` → 先頭の該当セクション（フォールバック）
4. **最初に位置を取得できたエイリアスを原点**とし、各エイリアスの相対差を保って配置先を計算
   `target = base + (src - src_base)`（負値は 0 にクランプ、[lib.rs:120](../src/lib.rs#L120)）
5. 編集セクション② — `create_object_from_alias(alias, layer, frame, length=0)` を順に実行
   - `length=0` は SDK 仕様で「長さ・追加位置を自動調整」。エイリアスにフレーム情報があればそちらが優先される
   - 既存オブジェクトと重なる場合やデータ不正の場合は SDK 側で失敗するため、失敗数としてカウントし継続
6. `試行 / 作成成功 / 作成失敗` をログ出力

> 補足: SDK の `create_object_from_alias` は複数オブジェクトのエイリアスデータを1回の呼び出しで生成できるが、本プラグインは**相対配置を自前で制御するため**あえて分割して1件ずつ呼び出している。

### 4.4 エイリアスからパスをコピー（オブジェクトメニュー）

[src/lib.rs:568](../src/lib.rs#L568)

1. 選択オブジェクトが0件なら情報ログを出して終了
2. 各オブジェクトのエイリアスを INI としてパースし、**全セクション・全キーの値**からパス候補を抽出
3. 抽出ルール（[lib.rs:128](../src/lib.rs#L128)〜）
   - 正規化: `¥` `￥` `＼` を `\` へ置換、前後の空白と `"` `'` を除去
   - パス判定: `X:\` / `X:/` で始まる、または `\\` で始まる（UNC）
   - 値の途中に埋め込まれたドライブレターも走査し、空白や `" ' ) ] } , ; |` で終端
   - 既知拡張子（`.png` `.mp4` `.wav` `.aup2` `.object` など20種）が見つかった場合は**そこで切り詰め**
   - カンマ区切りの各要素も個別に判定
   - 候補は出現順で**重複除去**
4. 候補0件なら情報ログを出して終了
5. 候補が**1件なら即コピー**、複数なら選択ダイアログ（§5.2）を表示
6. コピーしたパスをログ出力

### 4.5 トラックバーのパラメータをコピー（設定項目メニュー）

[src/lib.rs](../src/lib.rs) `copy_track_param`

1. 右クリックされた項目を `get_track_info` で判定。トラックバーでなければ情報ログを出して終了
2. `get_effect_item` で現在の設定値文字列を取得し、§3.3 の規約で分解
3. CopyAlias 形式のテキストとしてクリップボードへ書き出す

```ini
[CopyAlias.TrackParam]
version=1
effect=標準描画
effect_index=0
item=拡大率
value=0.00,100.00,直線移動,3
values=0.00,100.00
mode=直線移動
flags=3
param=0.0001          ; パラメータ（参照式含む）がある場合のみ
timecontrol=0,0,...   ; 時間制御データがある場合のみ
```

`value` は人が読むための生の値で、復元には分解済みの `values` / `mode` / `flags` / `param` / `timecontrol` を使う。

### 4.6 トラックバーのパラメータをペースト（設定項目メニュー）

[src/lib.rs](../src/lib.rs) `paste_track_param`

1. 編集セクション① — 対象項目の現在値・区間数・選択中オブジェクトを確定（トラックバーでなければ終了）
2. クリップボードを次の優先順で解釈する（`resolve_track_source`）
   1. **CopyAlias 形式** — `[CopyAlias.TrackParam]` セクションから復元
   2. **エイリアス形式** — `[Object.N]` を含む INI から、同じエフェクト名・出現順・キーの値を探す。見つからなければ同名キーの先頭
   3. **設定値そのもの** — 改行を含まず先頭が数値のテキストをそのまま値として解釈
3. **貼り付けダイアログ**（§5.3）で反映する要素を選択。キャンセル時は何もしない
4. 編集セクション② — 対象ごとに現在値を読み直し、選択された要素だけ差し替えて適用
   - 合成は**対象の現在値がベース**。選択されなかった要素は対象の値がそのまま残る
   - 加速・減速と中間点無視はフラグのビット単位で置き換える
   - 参照式フラグ（`8`）と、今後追加され得る未知のビットは**パラメータと連動**して転写する。パラメータを反映しない場合は貼り付け先のビットが維持される
   - 値の個数は対象の**区間数 + 1** に自動調整する（多ければ先頭から切り詰め、少なければ末尾値で補完）
   - 合成後に移動方法が無くなる場合は値を1つに切り詰め、フラグ・パラメータ・時間制御データを落とす
   - 項目が見つからないオブジェクトはスキップして継続
5. `対象 / 適用成功 / 項目なしスキップ / 設定失敗 / 値数調整` をログ出力

適用先は右クリックした項目のオブジェクトのみだが、ダイアログで「選択中の全オブジェクトの同じ項目にも適用」を有効にすると選択中オブジェクトへ一括適用する（右クリックしたオブジェクトは常に対象に含み、重複は除去）。

### 4.7 エフェクトのトラックバーを一括コピー（設定項目メニュー）

[src/lib.rs](../src/lib.rs) `copy_effect_tracks`

エフェクト名の右クリックからも、その配下の設定項目の右クリックからも実行できる（`item` は使わず `effect` / `effect_index` だけで対象を決める）。

1. `get_object_alias` でオブジェクト全体のエイリアスを取得し、§3.2 の規約でパース
2. `effect_name` と `occurrence` が一致するセクションのキーを**エイリアスの並び順**で列挙
3. 各キーに `get_track_info` を当て、**トラックバー項目だけ**を残す
4. 連番セクション形式でクリップボードへ書き出す（1件の場合は単一形式）

```ini
[CopyAlias.TrackParam.0]
effect=標準描画
item=X
values=0.00,100.00
mode=直線移動
flags=0
[CopyAlias.TrackParam.1]
effect=標準描画
item=Y
...
```

### 4.8 エフェクトのトラックバーを一括ペースト（設定項目メニュー）

[src/lib.rs](../src/lib.rs) `paste_effect_tracks`

1. クリップボードを `from_clipboard_text_multi` で読む（単一形式・連番形式の両方を受け付ける）
2. 貼り付け先エフェクトのトラックバー項目を列挙し、**項目名の一致**で対応付ける
   - コピー元の**エフェクト名は問わない**（`標準描画` の `X` を別のスクリプト効果の `X` へ貼れる）
   - 対応先が無い項目はスキップし、ダイアログに一覧表示する
3. **一括ペーストダイアログ**（§5.5）で、適用する項目と反映する要素を選ぶ
   - 要素の選択は**全項目共通の1セット**
4. 対象ごとに現在値と区間数を読み直して合成・適用する（§4.6 と同じ規則）
5. `対象オブジェクト / 適用成功 / 項目なしスキップ / 設定失敗 / 値数調整` をログ出力

## 5. ダイアログ仕様

両ダイアログとも `eframe::run_native`（egui）で**独立ウィンドウ**として起動し、`std::sync::mpsc` チャネルで結果を受け取る。**編集セクションの外側**で表示するため、編集ロックを保持したまま UI 待機することはない。

共通仕様（[src/gui.rs](../src/gui.rs)）:

| 項目 | 内容 |
|---|---|
| 表示位置 | `GetCursorPos` のマウス座標を基準にオフセット配置し、**モニタの作業領域内へクランプ**する（§5.4） |
| サイズ | 初期サイズは各ダイアログで指定。**最大サイズは固定せず**、最小 320 × 200 までリサイズできる |
| レイアウト | 決定ボタンは `TopBottomPanel::bottom` に固定し、可変長の内容はスクロール領域に入れる。内容が増えてもボタンがウィンドウ外へ押し出されない |
| フォント | `YuGothM.ttc` → `YuGothR.ttc` → `meiryo.ttc` → `msgothic.ttc` の順で最初に読めたものを Proportional/Monospace の先頭に挿入 |
| ライフサイクル | 生成した `egui::Context` をグローバルに登録し、プラグイン `Drop` 時に `close_all_plugin_dialogs()` で全て閉じる（ホスト終了・アンロード時の取り残し防止） |
| 結果受信 | ウィンドウ終了後に `try_recv()`。未送信ならキャンセル扱い |

### 5.1 プロパティ選択ダイアログ（`CopyAlias - プロパティ選択`）

- 初期サイズ: 420 × 480
- 構造: `egui_ltreeview` による3階層ツリー（残り領域いっぱいに広がるスクロール領域内）
  - **ブロック N**（＝コピー元オブジェクト単位、表示は1始まり）
  - **エフェクト名**（同名が複数ある場合は `エフェクト名 (2)` のように occurrence+1 を付記）
  - **`キー = 値`**（葉ノード、チェックボックス）
- 初期状態は**全項目チェック済み**、`全選択` / `全解除` ボタンあり
- 親ノードのチェックは配下全項目に伝播、配下が全てチェック済みのときのみ親がチェック表示になる
- `適用` → チェック済み `ApplyItem` を返す／`閉じる` → キャンセル

### 5.2 パス選択ダイアログ（`CopyAlias - パス選択`）

- 初期サイズ: 420 × 160
- コンボボックスから候補を1つ選択 → `コピー` / `キャンセル`
- 候補が1件の場合はダイアログを出さず即座に返す

### 5.3 トラックバー貼り付けダイアログ（`CopyAlias - トラックバーの貼り付け`）

- 初期サイズ: 460 × 480
- 貼り付け先（`エフェクト (n) / 項目`）とコピー元の表示
- `全選択` / `全解除` ボタン（選択できない要素はチェックされない）
- 反映する要素のチェックボックス。各行にコピー元の内容を併記する

| 要素 | 併記内容 | 選択可能な条件 |
|---|---|---|
| 値 | `0.00, 100.00` | コピー元に値がある |
| 移動方法 | `直線移動` / `移動無し` | 常に可 |
| 加速・減速 | `加速 + 減速` / `加速` / `減速` / `なし` | コピー元が移動あり |
| 中間点無視 | `ON` / `OFF` | コピー元が移動あり |
| パラメータ | パラメータ値（参照式なら `X*2（参照式）`） | コピー元か貼り付け先に存在する |
| 時間制御データ | カーブデータ | コピー元か貼り付け先に存在する |

パラメータと時間制御データは、**貼り付け先だけが持っている場合も選択できる**。コピー元が持っていない状態を貼り付けることで、貼り付け先の値を消す操作になる。

- 選択できない要素はチェックボックスを無効化し、選択状態も強制的に外す
- **適用後の値をライブプレビュー**表示し、値の個数が調整される場合は警告色で予告する
- 選択中オブジェクトが2件以上のときのみ「選択中の全オブジェクト(n件)の同じ項目にも適用」を表示（既定 OFF）
- 要素が1つも選択されていない場合は `貼り付け` ボタンを無効化

### 5.4 表示位置の決定

マウス位置に出しつつ、ウィンドウが画面外へはみ出さないようにする。座標系が2つ絡むため2段階で処理する。

| 段階 | 処理 |
|---|---|
| ウィンドウ生成時 | `ViewportBuilder::with_position` は**論理座標**を要求するが、この時点では DPI が不明なため暫定値を渡す |
| 最初のフレーム | `ViewportCommand::OuterPosition` を送って確定させる。このコマンドは**ウィンドウの実 DPI で物理座標へ変換**されるため、モニタごとに DPI が異なる環境でも正しい位置になる |

クランプの計算（`DialogWindow::clamped_position`）:

1. `GetCursorPos` でカーソル位置（物理ピクセル）を取得
2. `MonitorFromPoint(MONITOR_DEFAULTTONEAREST)` + `GetMonitorInfoW` で、**カーソルのあるモニタの作業領域**（タスクバーを除いた範囲）を取得
3. `カーソル位置 - オフセット` を作業領域内へ収める。ウィンドウが作業領域より大きい場合は左上を優先
4. `pixels_per_point` で割ってポイント単位へ戻す

Win32 の呼び出しが失敗した場合や Windows 以外では、クランプせずマウス基準の位置をそのまま使う。


### 5.5 一括ペーストダイアログ（`CopyAlias - トラックバーの一括ペースト`）

- 初期サイズ: 520 × 520
- 上段: 反映する**要素**のチェックボックス（全項目共通、`全選択` / `全解除` 付き）
	- 選択可否は全項目を通した論理和で決める（いずれかの項目で反映できる要素は選択可）
- 下段: 適用する**項目**のチェックリスト（`全選択` / `全解除` 付き）。各行に適用後の値をライブプレビュー表示
- 値の個数を調整する項目がある場合は件数を警告色で予告
- 対応先が無くスキップされた項目名を一覧表示
- 選択中オブジェクトが2件以上のときのみ「選択中の全オブジェクトの同じエフェクトにも適用」を表示（既定 OFF）
- 要素・項目のどちらかが未選択の場合は `貼り付け` ボタンを無効化

## 6. エラー処理・ログ方針

- 全メニューは `error = "log_only"` 指定。ハンドラが `Err` を返してもホストにダイアログを出さず、ログへ記録するのみ
- 「対象が無い」「解析できない」「キャンセルされた」といった**正常系の中断は `Ok(())` + info ログ**で表現する
- クリップボードのオープン／読み書き失敗のみ `Err`（`anyhow`）として扱う
- 一括処理（適用・生成）は**個々の失敗で中断せず、集計をログに出す**方針で統一
- ログは SDK の `LOG_HANDLE`（1メッセージ 1024 文字制限）経由でログウィンドウに出力される

主なログ文言:

| 状況 | レベル | メッセージ |
|---|---|---|
| 選択なし | info | `対象オブジェクトを選択してから実行してください。` |
| INI 解析不可 | info | `INI形式を解析できませんでした。表示対象（effect.name付きセクション）がありません。` |
| 適用キャンセル | info | `適用をキャンセルしました。` |
| 貼り付け元なし | info | `クリップボードに有効なエイリアス文字列がありません。` |
| パス候補なし | info | `エイリアス内にファイル/フォルダパスらしき値が見つかりませんでした。` |
| 適用結果 | info | `適用対象オブジェクト: n / 試行数: n / 適用成功: n / エフェクト不一致スキップ: n / 設定失敗: n / 値数調整: n` |
| 貼り付け結果 | info | `オブジェクト貼り付け / 試行: n / 作成成功: n / 作成失敗: n` |
| トラックバー以外の項目 | info | `「{項目名}」はトラックバー項目ではありません。` |
| トラックバー値の解釈不可 | info | `クリップボードからトラックバーのパラメータを読み取れませんでした。` |
| トラックバー貼り付け結果 | info | `トラックバー貼り付け / 対象: n / 適用成功: n / 項目なしスキップ: n / 設定失敗: n / 値数調整: n` |
| 終了時 | info | `プラグインを終了します。` |

## 8. 制限事項・留意点

1. **フォールバックなし** — 「エイリアスをコピー」は選択0件で何もしない。オブジェクト設定ウィンドウのフォーカスオブジェクトは参照しない
2. **Undo 単位** — 「エイリアスの値をペースト」は編集セクション②の全適用が1つの Undo にまとまる。ダイアログを挟むため、コピー処理と適用処理は別トランザクション
3. **オブジェクトハンドルの寿命** — 選択オブジェクトのハンドルを編集セクションを跨いで保持する設計のため、ダイアログ表示中に対象オブジェクトが削除されると適用が失敗する（失敗としてカウントされ、クラッシュはしない）
4. **エフェクトの対応付け** — 名前と出現順のみで対応付けるため、フィルタの並び順が異なるオブジェクト間では意図しない項目に適用される可能性がある
5. **貼り付けの重なり** — SDK 仕様上、既存オブジェクトに重なる位置には生成できない。相対配置の結果が既存オブジェクトと衝突すると作成失敗となる
6. **言語ファイルが実質未実装** — [i18n/English.copyalias.aul2](../i18n/English.copyalias.aul2) はセクション見出し `[English.copyalias.aux2]` のみで翻訳エントリが無く、メニュー名・ダイアログ文言は日本語固定
7. **ダイアログは非モーダル** — ホストのメインウィンドウとは独立したウィンドウとして開くため、開いたままホスト側を操作できる
8. **旧 C++ 実装** — [cpp/CopyAlias.cpp](../cpp/CopyAlias.cpp) は v1 系の実装で、メニューは「エイリアスをコピー」「エイリアスの値をペースト」の2つのみ。現行は Rust 実装（`src/`）
9. **設定項目メニューの表示条件** — SDK の仕様上、トラックバーのコピー/ペーストはテキストや色などトラックバー以外の項目の右クリックにも表示される。実行するとログに「トラックバー項目ではありません」と出るだけで、値は変更されない
10. **パラメータと時間制御データの推定** — 対象の `TrackInfo::timecontrol` が `true` で、移動方法より後ろの `|` 区切りが1つしか無い場合は、要素数（4以上か）による推定になる。実データの時間制御データは `0.353636,0.815934,0.159091,0.686813` の4要素で、しきい値ちょうどのため余裕が無い。3要素以下の時間制御データや、4要素以上のパラメータが存在すると誤判定する
11. **フラグビットの網羅性** — SDK ヘッダにも `aviutl2.txt` にもフラグの定義は記載が無く、`1 / 2 / 4 / 8` は実データから確認したもの。`16` 以上のビットが存在する場合はパラメータ側に紐づくものとして扱われる
12. **トラックバー貼り付けの Undo** — ダイアログ後の適用（一括適用を含む）がまとめて1つの Undo 単位になる
