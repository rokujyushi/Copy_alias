## CopyAlias v2.1.0

オブジェクト設定のトラックバー項目を右クリックして、値や移動方法を**要素ごとに選んでコピー / ペースト**できるようになりました。

これまでオブジェクト単位（エイリアス）でしか設定を持ち運べませんでしたが、「この項目の移動方法だけ他のオブジェクトに揃えたい」といったピンポイントな操作ができます。

### 新機能

**トラックバーのパラメータをコピー / ペースト**（オブジェクト設定の項目を右クリック）

`X`、`拡大率` などのトラックバー項目を右クリックしてコピーし、別の項目へ貼り付けます。貼り付け時は反映する要素を選べます。

- 値（各区間の値）
- 移動方法（直線移動、補間移動、スクリプト移動など）
- 加速・減速
- 中間点無視
- パラメータ（参照式を含む）
- 時間制御データ

チェックを外した要素は貼り付け先の設定がそのまま残ります。適用後の値はダイアログ上でプレビュー表示されます。

- **中間点数の違いを自動調整** — 中間点の数が異なるオブジェクトへ貼り付けると、値の個数を貼り付け先に合わせます（多ければ切り詰め、少なければ末尾値で補完）
- **複数オブジェクトへの一括適用** — 選択中のオブジェクトが複数ある場合、同じ項目へまとめて適用できます
- **貼り付け元は3種類** — CopyAlias でコピーした値のほか、エイリアス全文や設定値の文字列（`0.00,100.00,直線移動,3` など）もそのまま貼り付け元として使えます

### 改善

- **「エイリアスの値をペースト」でも値の個数を自動調整** — 中間点数の異なるオブジェクトへトラックバー項目を貼ったときに値がずれる問題を防ぎます。移動方法や加減速の扱いは従来どおりです
- **ダイアログの表示位置を改善** — マウス位置に表示しつつ、モニタの作業領域からはみ出さないように補正します。マルチモニタ環境と高 DPI 環境での位置ずれを修正しました
- **ダイアログをリサイズ可能に** — 内容が収まらない場合にウィンドウを広げられます

### 修正

- **項目数が多いときに決定ボタンが押せなくなる問題を修正** — 「エイリアスの値をペースト」で項目が多いと、ツリーに押し出されて「適用」ボタンがウィンドウ外へ出ていました。決定ボタンを下部に固定するようにしました
