## CopyAlias v2.1.0

オブジェクト設定のトラックバー項目を右クリックして、値や移動方法を**要素ごとにコピー / ペースト**できるようになりました。

### 新機能

**トラックバーのパラメータをコピー / ペースト**

`X`、`拡大率` などの項目を右クリックしてコピーし、別の項目へ貼り付けます。貼り付ける要素は選択できます。

- 値 / 移動方法 / 加速・減速 / 中間点無視 / パラメータ / 時間制御データ
- 中間点の数が違うオブジェクトへ貼り付けても、値の個数を自動調整します
- 選択中のオブジェクトが複数あれば、同じ項目へ一括適用できます

### 改善・修正

- 「エイリアスの値をペースト」でも、トラックバー項目の値の個数を自動調整するようにしました
- 項目が多いときに「適用」ボタンがウィンドウ外に出て押せなくなる問題を修正しました
- ダイアログが画面外にはみ出さないようにし、高 DPI 環境での位置ずれを修正しました

### インストール

`KuroNeko.CopyAlias-v2.1.0.au2pkg.zip` を AviUtl2 のプレビュー画面へドラッグ＆ドロップしてください。
